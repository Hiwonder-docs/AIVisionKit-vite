2. Quick Start ​

2.1 WonderLens AI Vision Module Basic Experience ​

2.1.1 Powering On the Device ​

NOTE

  • The supply voltage for the WonderLens AI vision module must not exceed 5 V. Always select a charging adapter or lithium battery that outputs 5 V or less.

  • Ensure sufficient supply voltage and power capacity. Otherwise, the WonderLens AI vision module may experience screen flickering, incorrect detection results, or other abnormal behaviors.

2.1.2 Operating Instructions ​

(1) Basic Operations ​

The WonderLens AI vision module features two joysticks located on the left and right sides. Each joystick can be toggled left, toggled right, or pressed downward. Functionally, these controls serve as the Navigation Joystick and the Function Joystick. The joystick in the upper-left corner of the screen functions as the navigation joystick, while the one in the upper-right corner serves as the function joystick, as shown in the following figure:

(2) Color Recognition ​

  1. Entering the Mode

    • Upon initial startup, the screen stays on the "Color Recognition" function bar.

    • Return to the main interface and toggle the Navigation Joystick until the "Color Recognition" menu bar appears at the top of the screen.

  2. Learning and Recognizing New Colors

    Before using the color recognition function, the target color must be learned. The learning steps are as follows:

    (1) On the main Color Recognition screen, toggle the Function Joystick to the pen icon to enter the learning interface.

    (2) Align the crosshairs in the center of the screen with the color patch to be learned. The selected color patch will be highlighted by a white bounding box.

    (3) Toggle the joystick left, then press the Function Joystick at the camera icon to begin learning. Once learning succeeds, a confirmation prompt appears on the screen.

    (4) After successful learning, whenever the vision module detects the recognized color in the frame, it immediately highlights the largest matching object and displays the corresponding color ID.

  • For instructions on deleting color recognition IDs and configuring related parameters, refer to [4.4.4 Function Introduction](./4.Software and Hardware Guide.md#section-4-4-4).

(3) Facial Recognition ​

  1. Entering the Mode

    Return to the main interface and toggle the Navigation Joystick until the "Facial Recognition" menu bar appears at the top of the screen.

  2. Detecting Faces

    Once this mode is entered, face detection starts running automatically. When a face is successfully detected, it is highlighted with a white bounding box.

  • For face recognition learning steps and parameter configuration details, refer to [4.4.4 Function Introduction](./4.Software and Hardware Guide.md#section-4-4-4).

(4) Tag Recognition ​

  1. Entering the Mode

    Return to the main interface and toggle the Navigation Joystick until the "Facial Recognition" menu bar appears at the top of the screen.

  2. Recognizing Tags

    Aim the camera at the tag. The tag will be outlined with an orange bounding box on the screen, and crosshairs will appear in its center.

    The WonderLens AI vision module can simultaneously recognize multiple tags with identical or different IDs.

    NOTE

    Maintain an appropriate distance from the tag so that the module can outline it for detection. If the tag is positioned too far from the WonderLens AI vision module, the tag will appear too small in the frame, preventing the module from recognizing it.

(5) Line Following ​

  1. Entering the Mode

    Return to the main interface and toggle the Navigation Joystick to the right until the "Line Following" menu bar appears at the top of the screen.

  2. Learning and Recognizing New Lines

    This function operates similarly to color recognition. The line must be learned prior to use. The learning steps are as follows:

    (1) On the main line following interface, first toggle the Function Joystick to the left, then short-press the button corresponding to the pen icon .

    (2) Align the crosshairs in the center of the screen with the line to be learned. Ensure that the line appears as straight or vertical as possible in the frame, and adjust the white arrow on the screen to match the direction of the target line.

    (3) Short-press the button corresponding to the camera icon to start learning. Adjust the lighting and angle to ensure that the white arrow remains stable without jittering, then wait for the learning result prompt. If learning fails, change the lighting conditions or use a more vivid color to restore the arrow to a stable state before attempting to learn again.

    (4) After successful learning, whenever the corresponding line color appears in the frame, the WonderLens AI vision module calculates the region of that color and draws an arrow.

  • For instructions on deleting line IDs and configuring related parameters in line following, refer to [4.4.4 Function Introduction](./4.Software and Hardware Guide.md#section-4-4-4).

(6) Number Recognition ​

  1. Entering the Mode

    Return to the main interface and toggle the Navigation Joystick to the right until the "Number Recognition" menu bar appears at the top of the screen.

  2. Recognizing Numbers

    Aim the camera at the number cards to perform classification testing. Each number card corresponds to a specific number. During operation, the screen displays the number with the highest confidence level along with its confidence value. A confidence value closer to 1.0 indicates a more reliable recognition result.

(9) Feature Learning ​

  1. Entering the Mode

    Return to the main interface and toggle the Navigation Joystick to the right until the "Feature Learning" menu bar appears at the top of the screen.

  2. Learning Features

    (1) On the main feature learning screen, toggle the Function Joystick to the left toward the pen icon to enter the learning interface.

    (2) Move the WonderLens AI vision module to frame the target, then press the Function Joystick button corresponding to the camera icon and wait for the module to finish learning.

    (3) After learning is completed, the displayed ID and P values are no longer 0. In this display, P represents the confidence level, where a value closer to 1 indicates higher similarity. ID represents the ID of the learned image that best matches the current frame.

  • For instructions on deleting IDs in feature learning, refer to [4.4.4 Function Introduction](./4.Software and Hardware Guide.md#section-4-4-4).

2.3 Hardware Preparation ​

2.3.1 Powering On ​

Toggle the power switch to the ON position. When the power LED indicators on the controller illuminate, startup is successful.

2.3.2 Charging ​

  1. Ensure that the power switch of the controller is set to the OFF position. Connect one end of the Type-C cable to the charging port of the controller and the other end to a USB charger.
  1. During charging, the LED indicators on the controller display the current charging status. When the battery is fully charged, all four white LEDs remain continuously lit. Disconnect the power cable promptly after charging is complete to prevent overcharging.

NOTE

The power switch must be set to the OFF position during charging. Otherwise, the battery may fail to charge fully. Disconnect the charger and power cable promptly once charging is complete to prevent battery damage caused by overcharging.

2.5 Introductory Projects ​

2.5.1 Buzzer Alarm ​

(1) Learning Objectives ​

  1. Knowledge Objectives: Get familiar with basic operations of the WonderLab programming platform. Understand the functions, sound-producing principles, and parameter meanings of volume, pitch, and beat for the buzzer module on the AiBlock controller. Master the basic programming logic of main loops and button event triggering.
  2. Skill Objectives: Proficiently complete basic operations of creating new projects and adding controller extensions in the programming software. Able to independently construct graphical programs for buzzer sounding and volume adjustment. Master the complete process of program connection, upload, and debugging.
  3. Literacy Objectives: Establish computational thinking for coordinating hardware with software routines. Understand the operational role of event-driven trigger mechanisms. Develop practical hands-on assembly and systematic program-debugging skills.

(2) Adding Extensions ​

  • Select AI Blocks Board under the Controller category.

(3) Core Blocks ​

BlockCategoryDescription
Play the designated musical note according to the configured parameters
Adjust the volume level of the buzzer
Trigger the corresponding program routine when the button is short-pressed

(4) Program Description and Upload ​

  • Complete Program

    1. Upon power-on, the main program executes continuously in a loop. Inside the loop, tone C2 plays continuously at a 1/2 beat in background mode, with a 1 s pause after each playback.
    2. Independent button controls are configured concurrently. Short-pressing the left button sets the buzzer volume to 100 and pauses for 2 s. Short-pressing the right button sets the buzzer volume to 50 and pauses for 2 s. The buttons can modify the buzzer volume parameter at any time during execution.

  • Program Upload

    Click Connect device, select the serial port, then click the upload button to complete the program transfer and test the execution results.

NOTE

The source files are available for download under Program Files.

(5) Execution Result ​

The device repeatedly plays tone C2 in the background for a 1/2-beat duration with a 1 s interval between notes. Short-pressing the left button adjusts the buzzer volume to 100 with a 2 s delay. Short-pressing the right button adjusts the buzzer volume to 50 with a 2 s delay.

2.5.2 Dual-State Intelligent Start-Stop Control for Line Following ​

(1) Learning Objectives ​

  1. Knowledge Objectives: Get familiar with extension adding operations in the WonderLab programming platform. Understand the functions and working principles of the 6-channel line-tracking sensor, RGB light module, dot matrix module, 180° block servo, and block long motor. Master the basic programming logic of reading sensor states and multi-condition branch judgment.
  2. Skill Objectives: Proficiently complete extension adding and hardware wiring operations for multiple module types. Able to independently construct graphical programs for line-tracking detection and driving the dot matrix, RGB light, servo, and motor to work collaboratively. Master the complete process of program connection, upload, and debugging.
  3. Literacy Objectives: Develop computational thinking for coordinating multi-hardware interactions. Understand the functional role of sensor-based condition assessments. Cultivate analytical debugging abilities and comprehensive hands-on engineering skills.

(2) Hardware Wiring ​

  • Connect the 6-channel line follower sensor to port A of the controller using a 4-pin module cable.
  • Connect the dot matrix module to port B of the controller using a 4-pin module cable.
  • Connect the RGB light module to port C of the controller using a 4-pin module cable.
  • Connect the 180° block servo to port S1 of the controller using a 3-pin servo cable.
  • Connect the long motor to port M1 of the controller using a modular servo cable.

(3) Adding Extensions ​

  • Select 6 Line follow sensor under the Input Module category.
  • Select 180° servo and Long motor under the Motion module category.
  • Select Dot matrix module and RGB module under the Output module category.

(4) Core Blocks ​

BlockCategoryDescription
Select the motor port, set the speed percentage, configure clockwise or counterclockwise rotation, and start the motor
Select the target motor port and stop the corresponding motor immediately
Select the servo port, set the speed percentage and target angle, choose automatic delay or no delay, and rotate the servo to the specified angle
Select the target servo port and stop the current servo movement so that the servo holds its current position
Read the black and white line detection status across all channels of the 6-channel line follower sensor to acquire tracking path information
Select the dot matrix module port and display a custom drawn pattern
Select the RGB light module port and set the desired illumination color

(5) Program Description and Upload ​

  • Complete Program

    1. The program initializes the 6-channel line follower sensor connected to port A.
    2. The main program enters a continuous loop to monitor the sensor status.
      • When the channels of the 6-channel line follower sensor detect a black line, the dot matrix module on port B displays the text "Hello", the RGB light module on port C illuminates in cyan, servo S1 rotates to 10° at 80% speed without delay, and motor M1 stops rotating.
      • If no black line is detected, the program further determines whether the sensor detects a white surface. Under this condition, the dot matrix module on port B draws a heart pattern, the RGB light module on port C illuminates in yellow, motor M1 starts rotating clockwise at 50% speed, and servo S1 stops operating. The process then repeats in the loop.

  • Program Upload

    Click Connect device, select the serial port, then click the upload button to complete the program transfer and test the execution results.

NOTE

The source files are available for download under Program Files.

(6) Execution Result ​

Upon powering on the device, the line follower sensor is initialized first. The program continuously loops to detect line following conditions. When a black line is detected, the dot matrix display shows Hello, the RGB light turns cyan, the servo rotates, and the motor stops. When a white surface is detected, the dot matrix display shows a heart, the RGB light switches to yellow, the motor rotates clockwise, and the servo stops.
